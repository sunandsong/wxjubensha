### 关键技术细节（别踩）

**两个 SDK 的差异只有两处**，写适配层抹平，业务代码一行不改：

| | `wx-server-sdk`（现在） | `@cloudbase/node-sdk`（目标） |
| --- | --- | --- |
| `doc(id).get()` | `res.data` 是**对象** | `res.data` 是**数组**，取 `res.data?.[0]` |
| `set` / `update` | `.set({ data: {...} })` | `.set({...})` 直接传对象 |
| `db.command` `_.set/inc/push/remove/exists`、`db.serverDate()` | — | **完全一致，不用动** |

`game/index.js` 只用到 `cloud.init` / `cloud.database()` / `cloud.getWXContext()` /
`cloud.DYNAMIC_CURRENT_ENV`，`getWXContext().OPENID` 改成从 JWT 解出来注入即可
（入口已有 `const OPENID = event.uid || realOpenid`，测试身份逻辑保留）。

**第 6 块的代价**：现在房主推进一幕所有人**瞬间**同步（WebSocket `watch`）。
改轮询后有 1.5~2 秒延迟，涉及 room / game / result / spy / wolf 五个页面。
计划：游戏中 1.5s、等待阶段 3s、`onHide` 停表。狼人杀天黑天亮体感最明显。
